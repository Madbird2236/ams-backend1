# AMS Creative Direction

Goal: AMS gets its own advertising identity — as creative in communication as it is professional in execution.

## Hard rules
1. **No literal clichés as the main idea.** No ads that are just walls, brushes, rollers, paint cans or painters at work. The service benefit is communicated *indirectly*.
2. **No logos** in initial creatives. Adriano generates images without a logo on purpose so Julia adds the AMS brand layer afterwards (logo, typography, colour, layout). The logo is the signature, not the idea: the concept itself must already carry an AMS clue (finish quality, precision, execution), so it could not be signed by a bank, insurer or real-estate agent.
3. **One image per file.** Never combine several creatives in one image.
4. **Slogans in Swiss Standard German** — no "ß", Swiss vocabulary, short (ideally ≤ 6 words), wordplay welcome if it works in Swiss usage.
5. **Originality > safety.** Premium visual quality: clean composition, generous negative space, one idea per image.
6. **Use references as inspiration, never copy** them (no same metaphor, layout or line).

## Mandatory process
1. **Brief:** service, target audience (e.g. retail brand managers, asset managers, architects, private owners), the one benefit to communicate, channel/format.
2. **Reference check:** re-read `creative/references/ANALYSIS.md` — which creative mechanics apply here?
3. **Three distinct concepts.** Each must use a *different* mechanism (e.g. visual metaphor / unexpected perspective / intelligent humour). Per concept:
   - Idea in one sentence
   - Visual description (what the viewer sees)
   - Slogan (Swiss German) + Portuguese translation for Adriano
   - Benefit communicated, and why it is indirect
4. **Pick the strongest** and justify against these criteria, scored 1–5:
   - Surprise — would someone stop scrolling?
   - Clarity — is the benefit understood in 3 seconds without explanation?
   - Ownability — could only AMS say this, not every painter?
   - Premium fit — does it raise the price we can charge, or cheapen us?
   - Execution feasibility — can it be produced at high quality?
   Reject any concept scoring < 3 on Clarity, however clever.
5. **Produce** the chosen concept: each image as a separate file in `creative/campaigns/<YYYY-MM>-<campaign-slug>/`, plus `brief.md` with the three concepts, the scores and the final slogan.

## Creative mechanics library (seed — extend from references)
- **Visual metaphor:** a finish so perfect it is mistaken for something else (glass, silk, sky).
- **Unexpected perspective:** show the *result's effect* (customers, light, calm, a store that opens on time) instead of the work.
- **Intelligent humour:** the absurd consequence of *not* choosing a professional, shown elegantly, never slapstick.
- **Contrast / time:** before/after told through one object, not a room.
- **Precision as hero:** a line, edge or corner so exact it becomes the subject.

## Benefits to communicate (pick one per creative)
Precision · reliability and deadlines (store openings) · cleanliness and minimal disruption · durability · premium finish · one partner for multiple trades · cross-border execution.
